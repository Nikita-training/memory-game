# Memory Game

Игра на поиск пар. Открываешь карточки по две, находишь все совпадения за минимум ходов.

## Функционал

- Поле 4×4 (16 карточек, 8 пар)
- Перемешивание при каждой новой игре
- Счётчики ходов и найденных пар
- Модалка победы
- Таблица лидеров (топ-10) в localStorage
- Закрытие модалок: кнопка, клик по фону, Escape

## Технологии

- JavaScript (ES6+)
- SCSS
- Без фреймворков
